## 为什么团队在寻找 AWS EC2 的替代方案

比起原始价格，账单的可预测性才是促使人们寻找替代方案的主要原因。在 AWS 上，计算、存储、网络和数据传输都是分开计费的，随着使用量的增长，总费用会悄然增加。现在还有一个新的推动因素：2025 年 7 月 15 日，AWS 取消了那个曾经孕育了无数副项目的 12 个月免费层级。新账户现在最多只能获得 $200 的赠金，并且有一个沙盒，在六个月后或赠金用完时（以先到者为准）就会自动关闭。

折扣机制也有其自身的怪癖。Savings Plans 和 Reserved Instances 可以提供 37-72% 的折扣，但前提是您必须为正确的实例系列签订一年或三年的合约；一旦猜错，就等于锁定了您无法完全利用的折扣。Spot Instances 针对可中断的工作最高可享 90% 的折扣，但其价格由内部算法而非可见的市场决定，因此很难预测工作负载下周的成本，或者何时会被回收。

然后是出站流量费用：$0.09/GB。一个月内向外传输 500 GB 数据就是 $45，这比其他地方一整台 VPS 的价格还要高。再加上 AWS 特有的机制（AMIs、安全组、实例元数据），迁移整个集群需要真正的工程时间，这正是为什么在扩容事件后过度预配资源的团队最终选择留在原地的确切原因。

## 何时 Vultr 是正确选择（何时不合适）

当您喜欢 EC2 的地方在于其工作流程时，Vultr 就显得非常合理：API、按小时计费、大量区域，以及无需更换供应商即可添加专用核心、GPU 或裸机的空间。具体来说：

- **您通过 API 或脚本管理服务器。** Vultr 的 API 驱动设置与 EC2 工作流高度契合，大部分使用习惯都可以直接套用，且其 32 个区域为您提供了比此价格级别的大多数替代方案更广泛的全球覆盖。
- **您的工作负载是突发性或短期的。** 带有月度上限的小时计费非常适合 CI 运行器、迁移服务器以及仅存在几个小时的开发环境。
- **您希望在同一个账户中使用相邻产品。** 裸机、GPU 和块存储可与 VM 并存，因此随着您的成长，单一供应商可以覆盖技术栈的更多部分。
- **可预测性比节省最后一分钱更重要。** 标明的价格就是实际价格；无需解决预留实例的难题。

在以下三种情况下，它不是正确的选择。如果您在欧洲只需要一台廉价的服务器而没有其他需求，Hetzner 的 €4.49 比 $24 便宜得多。如果您想要一个能为您处理所有事务的平台 — 优美的教程、一键托管数据库、应用平台 — DigitalOcean 的整个品牌就是建立在这之上的。如果您的应用程序确实依赖 AWS 原生服务（大规模的 Lambda、IAM 策略、CloudWatch），那么更换平台的工程成本将超过节省的费用。如实面对最后一种情况是关键：将一台简单的服务器从 EC2 迁移出来很容易，而迁移一个深度集成的技术栈则不然。

## 从 EC2 迁移：实际会发生哪些变化

有四件事会发生变化：计费模式、带宽计算、迁移路径，以及您遗留下来的托管服务。计费模式最容易适应。您将四种模式的购买系统（按需、预留、Savings Plans、Spot）换成了一种固定费率，这同时也是小时费率的上限。没有什么需要优化的，也没有什么需要猜测的。

带宽排在第二位。在 AWS 上花费 $45 的 500 GB 出站流量，可以轻松容纳在 $24 Vultr 套餐包含的 3 TB 之内。对于大多数 Web 工作负载来说，这是单项支出上最大的差异。

迁移本身是重建而非搬家。AMIs 和安全组配置无法带走；您需要从头开始（或通过配置管理）重新预配，并通过网络复制数据。Vultr 内置了快照和备份，如果您需要的磁盘空间超过套餐所含容量，还可以使用块存储。为一台简单的服务器预留一个平静的下午，对于任何有状态的内容则要预留更多时间。

您留在身后的是 AWS 的托管服务。Vultr 很好地涵盖了计算、存储和网络，并且它并不试图取代 200 多种更高级别的 AWS 产品。如果您的应用程序是一台服务器加上您自己管理的数据库，那么这种损失是看不见的。但如果它涉及三个 Lambda 函数、SQS 队列和 Cognito，那么在移动任何东西之前，请先计算一下工程成本。

## 常见问题

### Vultr 真的比 EC2 便宜吗？

是的，对于等效的共享 CPU VM 来说是这样的。一台 2 vCPU / 4 GB 的实例在 Vultr 上运行费用为 $24/mo，而在 EC2 上约为 $30，且 EC2 的数字不包括将现实场景推向 $115/mo 的额外费用：存储、Elastic IP、NAT 网关和 $0.09/GB 的出站流量费。Vultr 的套餐价格已经包含了流量配额。

### AWS 免费层级怎么了？

AWS 于 2025 年 7 月 15 日将其取消。新账户不再获得 12 个月的免费 t3.micro；而是获得最多 $200 的赠金，以及一个在六个月后或赠金用完时关闭的沙盒。“免费开始，因免费而留下”的道路已经消失，这也是为什么很多新项目现在从第一天起就开始比较替代方案。

### Vultr 的计费是如何运作的？

按小时计费，月费率作为上限。运行几小时的服务器只需支付几小时的费用，而运行整月的服务器永远不会超过标明的价格。无需做出按需与预留之间的决定。

### Vultr 套餐包含带宽吗？

包含。共享 CPU 套餐根据大小每月包含 0.5 到 5 TB 的出站流量，且已包含在套餐价格中。超出配额的部分将单独计费，因此在确定高流量工作负载之前，请检查当前针对您所选方案和地区的配额。
